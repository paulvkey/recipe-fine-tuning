# 基础规则数据

这里保存小型、可审查、可版本化的基础配置。运行流水线时不会修改这些文件；
采样生成的合并配置写入输出目录的 `generated_config/`。

- `typo_rules.json`：已人工确认的固定纠错。
- `noise_rules.json`：平台残留内容的正则清理规则。
- `protected_words.txt`：必须保留原样的专业词。
- `canonical_terms.json`：正确的标准烹饪词及允许检测的字段。
- `confusion_map.json`：正确字到常见误写字的单向映射。

自动纠错只会生成“标准词中一个字被易混字替代”的候选。例如标准词为“焯水”、
易混映射包含 `焯 -> 抄/绰`，采样中出现“绰水”后才生成 `绰水 -> 焯水`。
这种约束用于避免把正常近义表达错误地统一。
